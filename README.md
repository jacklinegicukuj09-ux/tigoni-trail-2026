#Tigoni Trail 2026 Website

## Project Overview
website is Designed for adventurers and nature lovers, the Tigoni Trail 2026 serves an all in one portal Kenyan Trekking event.
This application was developed strictly using vanilla web technologies to prioritize lightweight performance and direct DOM control.


## Technologies Used
* HTML5: Sematic document structure ('<header>', '<nan>', '<section'>, '<form>', '<footer>')
* CSS3: Card-based UI layout, flexbox positioning, and customized local aesthetic styling
* Javascript (ES6): Client-side event listening,DOM manipulation, and dynamic feedback handling

## Known bugs & solved Technical challenges

** DOM Selector Mismatches: Resolved element targeting issues where ID casing differences (trailForm vs TrailForm and confirmationMessage vs confirmationmessage) prevented Javascript from accessing the DOM elements.
** Element Visibility: Fixed visibility logic so the booking confirmation messageremains hidden until valid form submission trigger a style change to display:block

### Current known bugs :

* None . All interactive controls and page navigation functions seamlessly across local environments.
